# Park Hospital

A modern, highly optimized, and premium responsive web application built with **React + Vite**, featuring custom HSL HSL HSL curated design tokens, dynamic bento layout components, and advanced medical board showcases for Park Hospital, Lucknow.

---

## 🛠️ Tech Stack & Features
- **Core Framework**: React 19 + Vite
- **Styling**: Tailwind-free pure HSL Vanilla CSS for maximum efficiency and branding compliance
- **Routing**: `react-router-dom` with global scroll restoration
- **UX/UI Highlights**:
  - **Dynamic Bento Grid**: Overhauled specialties presenting critical care, diagnostics, maternal services, and general medicine.
  - **Premium Brand Integration**: Scaled high-resolution branding assets with hover scaling transitions.
  - **Medical Portals**: Dynamic bio boards for Dr. Rajeev Das and Dr. Neelam Biswas.
  - ** लखनऊ Location Mapping**: Embedded maps and direct 24x7 support lines.

---

## 🚀 Local Deployment Guide

1. **Clone the repository**:
   ```bash
   git clone https://github.com/101ANJ101/Park-Hospital.git
   cd Park-Hospital
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Compile production build**:
   ```bash
   npm run build
   ```
